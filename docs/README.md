# Chỉ mục tài liệu

- `design/`: kiến trúc, dữ liệu và thiết kế thực nghiệm.
- `guides/`: cẩm nang sử dụng và bảo vệ đồ án.
- `reports/midterm/`: báo cáo giữa kỳ chính thức.
- `reports/drafts/`: bản nháp, không dùng để nộp.
- `logs/`: nhật ký phát triển và quyết định kỹ thuật.

Các hình, bảng và dữ liệu kiểm toán sinh từ chương trình được đặt trong `../reports/`.
