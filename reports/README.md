# Chỉ mục kết quả

- `audits/`: kết quả kiểm toán tập dữ liệu.
- `figures/`: hình ảnh sinh từ phân tích và thực nghiệm.
- `tables/`: bảng tổng hợp kết quả, bao gồm 51 và 160 cấu hình.
- `pipeline/`: manifest và danh sách chia tập phục vụ pipeline.
- `results/`: đầu ra đánh giá mới.

Đây là artifact có thể đọc và trích dẫn. Log/checkpoint theo từng lần chạy nằm trong `../experiments/runs/`.
